# Reference sounds

Sounds whose feel you want the game to have. They're for comparison only and never ship: this folder sits outside Assets, so Unity doesn't import it, and git ignores everything here except this file.

## What to put in

A few of each, from games, films or libraries you like:

- growls and creature sounds
- chase music or chase cues
- whispers
- ambiences (night, wind, basements, empty rooms)
- anything else whose feel you want to match

## How to label them

Name each file for what it is, and put what you like about it in `notes.txt`, one line per file:

```
growl_resident_evil.wav | low, wet, close; you feel it more than hear it
chase_alien_isolation.mp3 | no melody, just pulse and scraping; builds without ever peaking
whisper_amnesia.wav | breathy, almost words, right in your ear
```

The "what you like" is the important part: it's what I match against when I tune the game's sounds.
